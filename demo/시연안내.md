# 온라인 멘토링 시연 조종판 — 설치·운영 안내 (Ver.1.0, 2026-11-20)

연구원에게 무용·미술 온라인 멘토링 시스템을 설명할 때 쓰는 **시연 전용 페이지**입니다.
학생·멘토가 모두 들어올 수 없으니, 시연 PC 한 대가 **가상 학생·가상 멘토**를 띄워 실제 화면으로 입장시키고 멘토링을 진행합니다.
운영자 1명과 연구원 1명은 **각자 PC에서 실제로 접속**해 진짜 버튼을 눌러 봅니다.

## 1. 어떻게 동작하나
- 실제 시스템을 그대로 씁니다. 다만 **시연 회차 `demo`** 에서만 진행합니다.
  - 실제 회차·명단·시트 「기록」「채팅」과 섞이지 않습니다.
  - 가상 참가자 이름과 연락처(010-0000-…)는 모두 지어낸 것입니다.
- 시연 PC의 조종판 안에 **진짜 학생 화면(휴대폰 크기)과 진짜 멘토 화면**이 여러 개 열립니다.
  - 카메라 대신 **움직이는 가상 영상**(사람 모양 + 이름표, 숨 쉬듯 흔들림, 무용 학생은 팔 동작)
  - 마이크 대신 **가상 목소리**(웅얼거리는 소리) → 받는 쪽 화면에 「말하는 사람」 초록 표시가 켜집니다.
- 가상 참가자는 이름 입력 → 장치 확인 → 입장까지 **스스로 진행**합니다.
- 운영자·연구원 화면에서는 대기실 화상, 학생 칸, 시작·종료, 멘토링실, 녹화가 **실제와 똑같이** 동작합니다.

## 2. 처음 한 번 준비
1. **무용 Apps Script를 Ver.2.7로, 미술 Apps Script를 Ver.1.5로** 새 버전 배포
   - 각 편집기에서 `Code.gs` 전체를 새 코드로 바꾸고 저장
   - 배포 > 배포 관리 > 연필 > 버전 「새 버전」 > 배포 (**새 배포 금지**: 주소가 바뀜)
   - `setup` 다시 실행은 필요 없습니다. 스크립트 속성도 그대로 둡니다.
2. 사이트 파일 올리기(이번 수정에 포함)
3. 따로 만들 코드는 없습니다. 조종판은 **평소 운영진 코드**로 엽니다.

## 3. 주소
| 누가 | 주소 |
|---|---|
| 시연 PC(조종판) | `https://mentoring.kartsproject.com/demo/` |
| 운영자(무용) | `https://mentoring.kartsproject.com/b/o.html?r=demo` → 「운영진」 + 운영진 코드 |
| 운영자(미술) | `https://mentoring.kartsproject.com/a/o.html?r=demo` → 운영진 코드 |
| 연구원 | 같은 주소 → 「연구원」을 고르고 연구원 코드 |

- 조종판 오른쪽 아래 「운영자·연구원 접속 주소」에 지금 분야의 주소가 나오고 「복사」로 복사할 수 있습니다.

## 4. 준비물
- **시연 PC 1대**(노트북 가능, 크롬 권장, 화면은 클수록 좋음)
  - 무용은 가상 참가자 13명(학생 12·멘토 1), 미술은 20명(학생 16·멘토 4)의 화면을 함께 돌립니다.
  - 가상 영상을 작게(학생 400×300) 보내지만, 미술은 **유선 인터넷·전원 연결**을 권장합니다.
- **운영자 PC 1대, 연구원 PC 1대** — 시연 PC와 다른 PC(같은 방이면 이어폰 권장)
- 조종판은 시연 PC에서 소리를 내지 않습니다(크게 볼 때 「소리 듣기」를 켜면 그 화면 소리만 들림).

## 5. 시연 순서
1. 시연 PC에서 조종판을 엽니다.
2. 오른쪽 위에서 **무용 / 미술**을 고르고 **운영진 코드**를 넣습니다.
3. **진행 속도**를 고릅니다.
   - 무용: 학생 1명당 2분 / 3분 / 5분
   - 미술: 전체·분반 시간이 짧게 / 보통 / 여유 있게
4. **「시연 시작」** → 시연 회차가 지금 시각 기준으로 만들어지고, 가상 멘토·학생이 차례로 입장합니다.
5. 운영자·연구원이 각자 PC에서 위 주소로 들어옵니다(시작 전에 들어와 있어도 됩니다).
6. 끝나면 **「시연 끝내기」** → 가상 참가자가 모두 나가고 시연 회차가 닫힙니다.
   - 다시 하려면 「처음부터 다시」(진행 상태를 비우고 새로 시작)

### 무용 자동 진행
| 순서 | 보이는 것 |
|---|---|
| 1 | 가상 학생이 몇 초 간격으로 대기실에 입장(9~12번은 자기 대기 시각에) |
| 2 | 가상 멘토(정다온)가 멘토링실에 입장 |
| 3 | 약 2분 뒤 첫 학생 멘토링 시작 — 학생 화면이 멘토링실로 바뀌고 멘토와 연결 |
| 4 | 멘토와 학생이 번갈아 말함, 멘토 설명 중 학생이 가끔 팔 동작 |
| 5 | 3번 학생은 지각 → 운영 화면에 빨간 테두리·전화 아이콘, 늦게 들어오면 다음 차례로 |
| 6 | 6번 학생은 멘토링 중 연결이 잠깐 끊겼다가 8초 뒤 자동으로 다시 들어옴 |
| 7 | 정해진 시간이 지나면 종료 → 다음 학생 시작, 마친 학생은 창을 닫음 |
| 8 | 대기실에서는 가끔 한 학생이 짧게 말함(말하는 사람 표시 설명용) |

- 시연 회차에서는 멘토·학생·운영 화면의 **타이머도 시연 시간**(예: 3분)에 맞춰집니다.
  - 그래서 「2분 남음 노랑」「1분 전 소리」도 짧은 시간 안에 볼 수 있습니다.
- 운영자가 운영 화면에서 직접 [시작]·[이 학생 종료]를 눌러도 됩니다. 조종판은 서버 상태를 따라갑니다.
- 운영자가 「녹화 시작」을 누르면 운영자 PC에 **실제 녹화 파일**이 만들어집니다(시연용 폴더를 고르세요).

### 미술 자동 진행
| 순서 | 보이는 것 |
|---|---|
| 1 | 가상 멘토 4명(강민서·윤재원·송하린·임도경)과 학생 16명 입장, 마지막 학생은 늦게 |
| 2 | 전체 멘토링 — A조 멘토가 설명, 중간에 한 학생이 손들고 질문 |
| 3 | 분반 — 학생·멘토가 조별 방(A~D조)으로 이동, 조마다 멘토와 학생이 번갈아 말하고 한 학생이 손들기 |
| 4 | (켰을 때) 조마다 1명이 작품 사진을 올림 → 멘토 화면에 크게 |
| 5 | 다시 전체 — 마무리 |
| 6 | 마침 · 모두 퇴장 → 학생 화면에 「멘토링이 모두 끝났습니다」 |

- 「진행 순서」의 **「지금」** 버튼으로 기다리지 않고 바로 다음 단계로 넘길 수 있습니다.
- 운영자가 운영 화면에서 직접 단계를 바꿔도 가상 참가자가 그대로 따라갑니다.
- 「작품 사진 자동 올리기」를 켜면 사진이 미술 드라이브의 **「시연」 폴더**에 저장됩니다(시연 뒤 지워도 됨).

## 6. 조종판 화면
- 위: **가상 멘토** 화면, 아래: **가상 학생** 화면(휴대폰 모양)
  - 초록 테두리 = 지금 말하는 중, 보라 테두리 = 멘토링 중
  - 칸 아래에 그 참가자의 상태(입장 화면 · 장치 확인 · 대기실 · 멘토링 중 · 마침 · 나감)
- 칸을 **한 번 누르면** 오른쪽 「직접 조작」에서 그 참가자를 움직일 수 있습니다.
- 칸을 **두 번 누르면(또는 ⤢)** 그 화면을 크게 봅니다 → 「학생에게는 이렇게 보입니다」 설명용
  - 크게 보는 동안만 다른 사람 영상을 받아 학생 화면이 실제와 똑같이 보입니다.
  - Esc 또는 「닫기」로 돌아갑니다.

### 직접 조작
| 버튼 | 하는 일 |
|---|---|
| 입장시키기 / 퇴장시키기 | 그 참가자 화면을 열거나 닫음 |
| 말하기 (8초) | 가상 목소리를 냄(마이크가 꺼져 있으면 켰다가 다시 끔) |
| 연결 끊기 | 창이 닫혔다가 8초 뒤 다시 열려 자동으로 다시 입장(새로고침과 같음) |
| 손들기 / 내리기 | 미술 학생 |
| 작품 사진 올리기 | 미술 학생 — 가상 그림 1장을 올림 |
| 춤 동작 보이기 | 무용 학생 — 영상 속 팔 동작 |
| 크게 보기 | 위와 같음 |

- **「자동 진행」을 끄면** 시간이 되어도 다음으로 넘어가지 않습니다. 멘토링 중인 두 사람의 대화만 계속됩니다.

## 7. 주의
- 시연이 끝나면 꼭 **「시연 끝내기」**를 누르세요.
  - 누르지 않으면 운영 화면 회차 탭에 「demo회차」가 6시간 동안 보입니다(학생 자동 입장에는 영향 없음).
- 시연 회차는 주소에 `?r=demo`를 붙였을 때만 들어가집니다. 실제 학생이 잘못 들어올 일은 없습니다.
- 운영진 코드는 조종판 탭에만 기억되고(탭을 닫으면 지워짐) 파일에 남지 않습니다.
- 시연 PC가 느리면: 진행 속도를 「빠르게」로, 크게 보기는 한 번에 하나만, 다른 프로그램은 닫기

## 8. 문제 해결
| 증상 | 확인 |
|---|---|
| 「시연 회차를 만들지 못했습니다」 | Apps Script를 무용 Ver.2.7 / 미술 Ver.1.5로 **새 버전** 배포했는지 |
| 「운영진 코드가 맞지 않습니다」 | 스크립트 속성 `OPS_CODE` 값(무용·미술 각각) |
| 가상 학생 칸 아래 「확인 필요」 | 그 칸을 눌러 오류 문구 확인 → 「처음부터 다시」 |
| 운영 화면에 가상 학생 영상이 안 나옴 | 대기실 화상(Cloudflare SFU) 설정과 시연 PC 인터넷 확인 |
| 소리가 시연 PC에서 남 | 「소리 듣기」를 끄기, 운영자·연구원 PC는 다른 곳에 |

## 9. 바뀐 파일
- 새 파일: `demo/index.html`, `demo/demo.js`, `demo/시연안내.md`, `test/e2e-demo.js`
- `b/apps-script/Code.gs` Ver.2.7 · `a/apps-script/Code.gs` Ver.1.5 — 시연 회차
- `b/index.html` · `b/m.html` · `a/index.html` · `a/m.html` — 맨 앞에 시연 고리 한 줄(평소에는 아무 일도 안 함)
- `b/meet.js` — 시연 회차의 짧은 멘토링 시간을 화면 타이머에 맞춤
- `a/sfu.js` — 조종판 안의 가상 참가자는 다른 사람 영상을 받지 않음(시연 PC 부담 줄이기)
- 모든 페이지 캐시 번호 `?v=2200`
