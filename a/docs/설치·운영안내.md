# 미술 온라인 멘토링 — 설치·운영 안내 (Ver.1.12, 2026-11-20)

전체 멘토링 → 분반 멘토링(멘토 1 : 학생 3 안팎) → 다시 전체로 진행하는 미술분야 심화 멘토링용 화상 시스템입니다. 영상은 **Cloudflare Realtime SFU**가 중계하고, 녹화는 **녹화 PC 1대**가 전체·분반 FHD 파일로 자동 저장합니다.

## 0-3. Ver.1.12 — 같은 학생 중복 접속 시 먼저 들어온 화면 종료 · 시연 조종판 삭제 (2026-11-20)
> **Apps Script `Code.gs`를 Ver.1.6으로 바꿔 넣고 「새 버전」으로 배포해야 합니다.**

- **같은 이름·생년월일로 다른 기기(또는 다른 창)에서 학생이 다시 들어오면, 먼저 들어와 있던 화면은 바로 종료**됩니다.
  - 종료된 화면에는 「다른 기기에서 접속했습니다」 안내가 뜨고 카메라·마이크가 꺼지며 연결이 끊깁니다.
  - 그 창을 새로고침해도 자동으로 다시 들어가지 않습니다.
- **시연 조종판(`/demo/`)과 시연 회차(`demo`)를 모두 삭제**했습니다(Code.gs Ver.1.6에는 시연 회차 기능이 없음).
- 무용에서 고친 것 중 미술에 맞는 것은 모두 들어 있습니다.
  - 소리 크기 버튼, 카메라 끄기 바로, 영상 연결(Cloudflare 연결 확인 후 받기), 운영진 누구나 녹화, 아이폰 입력 칸, 연락처 전화 팝업.
  - 무용의 「멘토링실 | 대기실」 오가기는 미술에 대기실이 없어 해당하지 않습니다. 미술은 운영진이 「듣기」로 고른 방에만 카메라·마이크가 나가 이미 같은 방식입니다.

## 0-2. Ver.1.11 — 운영진 누구나 녹화 · 영상 연결 고침 · 소리 크기 (2026-11-20)
사이트 파일만 바뀜(Code.gs 그대로).
- **녹화는 운영진 누구나**: 다른 PC가 녹화 중이어도 묻지 않고 이 PC도 함께 녹화합니다.
  - 나중에 켠 PC는 「예비 녹화」로 저장됩니다(파일 이름 끝 `_예비PC`).
  - 「녹화 조각 합치기」로 주 녹화의 빈 곳을 채울 수 있습니다.
- **영상 연결**: Cloudflare 중계와 연결이 이어진 뒤에 다른 사람 영상을 받도록 고쳤습니다.
  - 「Session appears to be disconnected」 오류로 화면이 안 보이던 문제입니다.
  - 콘솔에 `sfuInfo()`를 입력하면 연결 상태가 보입니다.
- **카메라 끄기**: 운영진 「내 카메라」가 누르면 바로 꺼집니다.
- **소리 크기** 버튼(학생·멘토·운영진·연구원): 내 마이크 0~200%, 듣는 소리 0~100%, 이 기기에 저장.

## 0. Ver.1.9 — 무용과 같은 디자인·기능 (2026-11-19)
> **Apps Script `Code.gs`를 Ver.1.4로 바꿔 넣고 「새 버전」으로 배포해야 합니다**(학생 입장 시간 제한).
> 바꾸지 않아도 나머지는 그대로 동작하고, 입장 시간 제한만 빠집니다.

### 디자인(무용과 같은 「키노트 다크」)
- 학생·멘토·운영·입장 화면 모두 검정 무대, 둥근 판, 유리 띠로 바꿨습니다.
  - 파랑 = 고른 것·강조, 초록 = 말하는 사람, 노랑 = 크게 보기·작품, 빨강 = 녹화·주의.
- 학생·멘토 아래 조작 줄을 **떠 있는 둥근 아이콘 막대**로 바꿨습니다(파랑→보라→분홍 테두리).

### 운영 화면
- **떠 있는 조작 막대**(방 보기 가운데 아래):
  - 🎥 **내 카메라**: 켜면 지금 듣고 있는 방에 「운영 ○○」 칸으로 보이고 녹화에도 들어갑니다.
  - 🎤 **내 마이크**: 누르면 계속 켜기/끄기. **길게 누르거나 스페이스바**를 누르고 있는 동안만 듣고 있는 방에 말합니다.
  - ⏺ **녹화**(운영진만, 예전 「이 PC에서 녹화」 스위치):
    - 회색 「녹화 켜기」 → 누르면 저장 폴더 고르기 → 노랑 「녹화 대기」.
    - 「멘토링 시작」부터 빨강 「녹화 중」(예비 녹화 PC는 「예비 녹화 중」).
    - 누르면 저장하고 끕니다(확인 창).
  - 위 띠 오른쪽에도 빨간 「녹화 중」 표시.
- 방 판마다 있던 「누르고 말하기」는 없앴습니다(조작 막대 마이크·스페이스바로).
- 방 판의 **「듣기」**는 고르면 파랑→보라 「듣는 중」으로 바뀌고, 그 방 판에 파란 테두리, 다른 방 판은 흐리게.
- **접속 현황**: 들어오지 않은 학생 줄에 상태 알약(미접속/연결 끊김)과 오른쪽 📞 **전화 아이콘**.
  - 누르면 학생·보호자 번호가 팝업으로 보이고, 번호를 누르면 전화가 걸립니다.
- **공지 띄우기를 없앴습니다**(운영 화면 칸, 학생·멘토 화면의 공지 띠). 전할 말은 마이크로 해 주세요.

### 학생 입장 시간(Code.gs Ver.1.4)
- 학생은 **회차 당일, 시트 「회차」의 「시작」 30분 전부터** 들어올 수 있습니다(예: 10:00 시작 → 9:30부터).
- 그 전에 들어오면 「**멘토링 시간이 아닙니다.** 11월 21일(토) 오전 9:30부터 입장할 수 있습니다.」가 보입니다.
- 한 번 들어온 학생은 그날 시간과 상관없이 다시 들어올 수 있습니다(새로고침·재접속).
- 리허설(`test`)과 날짜가 빈 회차는 언제나 들어올 수 있습니다.

## 3. 처음 설정 (한 번만)

### ① 구글 시트 + Apps Script
1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다(예: `K예술영재_미술멘토링`).
2. 메뉴 **확장 프로그램 › Apps Script** → 왼쪽 `Code.gs`의 내용을 모두 지우고 `a/apps-script/Code.gs` 전체를 붙여 넣고 저장(💾).
3. 왼쪽 **⚙ 프로젝트 설정 › 스크립트 속성 › 스크립트 속성 추가**에 아래를 넣습니다.

| 속성 | 값 |
|---|---|
| `CF_SFU_APP_ID` | Cloudflare 대시보드 › Realtime › SFU › `karts-art-mentoring`의 **App ID** |
| `CF_SFU_APP_TOKEN` | 같은 화면의 **API Token**(앱을 만들 때 한 번만 보이는 값) |
| `CF_TURN_KEY_ID` (권장) | 무용 Apps Script에 넣은 값과 **같은 값** — 학교·기관 망(UDP 차단)에서도 연결되게 |
| `CF_TURN_API_TOKEN` (권장) | 무용과 같은 값 |
| `MENTOR_CODE`·`OPS_CODE`·`RESEARCH_CODE` (선택) | 비워 두면 setup이 자동으로 만들어 줍니다 |

> 비밀키는 **스크립트 속성에만** 넣습니다. 시트·GitHub·카톡에 적지 마세요.

4. 편집기 위쪽 함수 목록에서 **`setup`** 선택 → **실행** → 권한 허용(내 계정 › 고급 › 이동 › 허용: 시트·드라이브·외부 서비스 연결).
5. 아래 **실행 로그**에서 확인:
   - `멘토 코드 / 운영진 코드 / 연구원 코드` — 메모해 두고 멘토·운영진에게 전달
   - `SFU 연결 시험: 성공` — 실패라면 App ID·Token을 다시 확인
   - 시트에 탭 「명단」「멘토」「회차」「기록」「관찰 메모」가 생기고, 드라이브에 `K예술영재_미술멘토링_작품사진` 폴더가 생깁니다.
6. **배포 › 새 배포** → 유형 ⚙ **웹 앱** → 실행: **나** / 액세스 권한: **모든 사용자** → 배포 → **웹 앱 URL** 복사.
7. 그 URL을 `a/config.js`의 `API:`에 넣습니다(URL을 보내 주시면 반영해 드립니다).

### ② 코드를 고친 뒤 다시 배포할 때
**배포 › 배포 관리 › ✏ › 버전: 새 버전 › 배포** (새 배포를 만들면 주소가 바뀌니 하지 마세요). 시트 머리글이 바뀐 경우 `setup`을 한 번 더 실행합니다.

> **Ver.1.7부터 Apps Script `Code.gs`(Ver.1.3)를 꼭 바꿔 넣어야 합니다** — 영상 멈춤 방지(화질만 바꿀 때 끊지 않고 바꾸기), 「모두 퇴장시키기」가 새 Code.gs에 들어 있습니다. 바꾸지 않으면 「모두 퇴장시키기」가 「unknown op」로 실패합니다.

## 4. 시트 입력

| 탭 | 열 | 예 |
|---|---|---|
| 명단 | 회차 · 이름 · 생년월일 · 조 · 학생 연락처 · 보호자 연락처 | `2` · `홍길동` · `20120315` · `A` · `010-…` · `010-…` |
| 멘토 | 회차 · 멘토 · 조 | `2` · `(멘토 이름)` · `A` |
| 회차 | 회차 · 날짜 · 시작 · 마침 | `2` · `2026-11-21` · `10:00` · `12:00` |

- 조는 `A`·`B`·`C`·`D`(또는 `1`~`9`). 학생·멘토 모두 같은 글자로 맞추면 분반에서 자동으로 같은 방에 들어갑니다.
- 생년월일·연락처 열은 글자 형식으로 맞춰 두었습니다(앞자리 0 유지). 생년월일을 비우면 이름만으로 입장합니다.
- 회차의 **시작·마침 시각**만 씁니다(운영·멘토 화면 위 띠에 참고용으로 작게 「마침까지 n분」, 학생 화면에는 없음). 분반은 진행에 따라 운영진이 버튼으로 시작·종료합니다.
- 예전 6칸 형식(전체1 시작·분반 시작·전체2 시작)으로 만든 시트도 그대로 읽습니다. `setup`을 한 번 더 실행하면 4칸(회차·날짜·시작·마침)으로 정리됩니다.
- **멘토·학생 자리는 명단 순서대로 고정**됩니다. 들어오지 않은 사람은 검은 칸에 이름이 보입니다.
- 시트는 1분마다 다시 읽습니다. 고친 내용은 1분 안에 반영됩니다.

## 5. 진행 방법

### 운영진 (`o.html`)
- **위 진행 버튼**(실수 방지로 **두 번** 누름 — 첫 번째에 빨갛게 「한 번 더 누르면 …」):
  - 시작 전 → **「멘토링 시작」**: 모두 전체 방으로, 녹화 시작
  - 전체 → **「분반 시작」**: 학생·멘토가 각 조 방으로 바로 이동(학생 마이크 자동 켜짐)
  - 분반 → **「분반 종료 · 전체로」**: 모두 전체 방으로 모임(학생 마이크 꺼짐)
  - 전체 → **「마침」**: 녹화 저장 후 멈춤
  - 마침 → **「모두 퇴장시키기」**(두 번 누름): 학생·멘토 화면에 「멘토링이 모두 끝났습니다」가 뜨고 카메라·마이크가 꺼지며 연결이 끊깁니다. 실수했으면 「다시 전체로」로 되돌릴 수 있습니다.
  - 분반은 진행에 따라 몇 번이든 다시 할 수 있습니다. 위 띠에 지금 단계와 경과 시간이 보입니다.
- **방 보기**: 학생·멘토 화면과 **같은 배치**로 보입니다 — 전체는 한 판(멘토 영역 2×2 크게 · 학생 영역 6×2 작게), 분반 중에는 조마다 한 판(2×2, 각 판은 멘토 크게 · 학생 한 줄), 칸은 명단 순서(미참여자는 검은 칸에 이름). 각 판의 **「듣기」**로 그 방 소리만 듣고, **「누르고 말하기」**(또는 **스페이스바**를 누르고 있는 동안) 그 방에만 말합니다. 칸을 누르면 그 방의 「크게 보기」를 지정·해제합니다.
- **내 카메라·마이크**(위 띠 「카메라 꺼짐/켜짐」 「마이크 꺼짐/켜짐」, 운영진·연구원 모두): 카메라를 켜면 **지금 듣고 있는 방**의 학생 줄 끝에 「운영 ○○」 칸으로 보이고 녹화에도 들어갑니다. 마이크를 켜 두면 누르지 않아도 그 방에 소리가 들립니다(끄면 「누르고 말하기」만).
- **조 배정**: 학생 이름을 끌어서 다른 조로 옮기면 그 학생이 바로 이동합니다(원래 조와 다르면 노란 테두리).
- **접속 현황**: 들어오지 않은 학생과 학생·보호자 연락처(누르면 전화). **「전체 접속자 보기」**를 누르면 팝업으로 멘토·운영진·연구원·학생 전체의 접속 여부와 지금 있는 방(전체/○조)이 보입니다(녹화 PC는 「녹화」, 말하는 중인 운영진·연구원 표시, 자동으로 새로 고침, 바깥을 누르거나 Esc로 닫기). 운영진·연구원은 한 번이라도 들어온 사람만 나옵니다(나간 사람은 「나감」).
- **관찰 메모**(연구원·운영진): 지금 듣고 있는 단계·조와 함께 시트 「관찰 메모」에 저장.
- 연구원은 단계 바꾸기·조 배정·녹화는 할 수 없고 보기·듣기·말하기·메모만 합니다.

### 녹화 (녹화 PC 1대)
1. 녹화할 PC(크롬)에서 운영진으로 입장 → 위의 **「이 PC에서 녹화」** 켜기 → 저장 폴더 고르기(처음 한 번, 다음부터 기억).
2. 「멘토링 시작」부터 「마침」까지 자동으로 나눠 저장합니다(시작 전·마친 뒤는 녹화하지 않음). 한 회차가 끝나면 **6개 파일**이 남습니다(4개 조 기준).
   - `261121_1000_미술_2회차_전체_분반전.mp4`
   - `261121_1100_미술_2회차_분반1_A조_어민선.mp4` · `…_분반2_B조_강이룬.mp4` · `…_분반3_C조_이푸로니.mp4` · `…_분반4_D조_임민재.mp4`
   - `261121_1150_미술_2회차_전체_분반후.mp4`
   - 분반을 한 번 더 하면 `…_분반1_A조_…_2차`, 그 뒤 전체는 `…_전체_분반후2`로 이어집니다.
   - **녹화 화면 구성**: 프로젝트 틀(위 「2026 K예술영재 프로젝트 · 미술분야 심화 멘토링」, 아래 주최·주관 로고) 안에 **위 멘토 · 아래 학생**. 전체 파일은 **멘토 영역(가로 2 × 세로 2, 크게)**과 **학생 영역(가로 6 × 세로 2, 작게)**을 바탕색으로 나눠 보입니다. 분반 파일은 오른쪽 위에 「소그룹 멘토링 A」. 들어오지 않은 사람은 검은 칸에 이름. 화면 공유·작품 사진·크게 보기가 있으면 **가운데 크게(노란 테두리), 멘토는 양옆에 작게**. 말하는 사람은 초록 후광·소리 아이콘.
   - 분반 중 PC가 버거우면 자동으로 **「분반_4분할」 1개 파일**로 바꿔 끊기지 않게 합니다.
3. 녹화 상자에 파일 이름·시간·크기가 보입니다. 이상이 생기면 빨갛게 깜빡입니다.
   - 녹화가 멈추면 새 파일로 다시 시작(2분에 3번까지), 폴더 쓰기가 막히면 예비 사본으로 계속, 창이 갑자기 닫혀도 다음 입장 때 **자동 복구**.
   - 「소리가 녹음되지 않고 있습니다」가 뜨면 화면을 한 번 클릭하세요(브라우저 자동재생 제한). 소리가 풀리면 새 파일로 이어서 소리까지 녹음합니다.
4. 녹화 PC가 없으면 모든 운영진 화면 위에 **「녹화 PC가 없습니다!」**가 뜹니다(전체·분반 진행 중).
5. 끝나면 스위치를 끄거나 「나가기」 → 저장 완료 후 나갑니다.

### 끊김 없는 녹화 — 이어 녹화 · 예비 녹화 · 조각 합치기 (Ver.1.8)
녹화 내용이 비지 않도록 세 겹으로 지킵니다.

1. **이어 녹화(자동)**: 녹화가 멈추거나(8초 이상 데이터 없음) 소리가 늦게 풀려 새 파일로 바꿀 때, **새 파일을 먼저 시작하고 앞 파일은 새 파일이 돌기 시작한 뒤에 멈춥니다.** 두 파일이 1~2초 겹치므로 그 사이 내용이 빠지지 않습니다. 단계가 바뀔 때도 같은 방식(1.5초 겹침).
2. **예비 녹화(권장 — 두 번째 PC)**: 다른 운영진 PC에서도 「이 PC에서 녹화」를 켜면 「다른 PC가 이미 녹화 중입니다」가 뜹니다 → **[확인]** = 예비 녹화.
   - 예비 녹화 PC는 주 녹화와 같은 화면을 따로 녹화합니다. 파일 이름 끝에 `_예비PC`가 붙습니다(예: `…_분반1_A조_어민선_예비PC.mp4`).
   - 녹화 상자 제목 옆에 「주 녹화」/「예비 녹화」, 「전체 접속자 보기」에 「예비 녹화」 표시. 주 녹화 PC가 꺼져도 예비 녹화가 있으면 「녹화 PC가 없습니다!」 경고는 뜨지 않습니다.
   - 같은 PC에서 두 번 녹화하는 것은 하지 않습니다(그 PC가 버거우면 둘 다 끊기기 때문 — 다른 PC여야 의미가 있음). 예비 녹화 PC도 받기 50Mbps 이상, 전원 연결.
3. **녹화 기록표**: 녹화 폴더에 `_녹화기록_2회차_주_(이름).tsv`(예비 PC는 `_예비_`)가 함께 저장됩니다. 파일마다 시작 시각(1/1000초)이 적혀 있어, 조각·예비 녹화를 정확한 자리에 이어 붙이는 데 씁니다. **지우지 마세요.**

**멘토링이 끝난 뒤 — 「녹화 조각 합치기」(맥)**
- 하는 일: 같은 단계가 여러 파일로 나뉘었으면 **한 파일로 이어 붙이고**, 주 녹화가 빈 곳(PC 멈춤·창 꺼짐)은 **예비 녹화로 채웁니다**. 단계별 6개 파일 구성은 그대로입니다.
  - 조각만 이어 붙이면 화질 손실 없이 몇 초~몇 분. 예비 녹화로 채우면 그 단계 파일을 다시 압축합니다(1시간 분량 M3 맥 기준 약 5~10분).
  - 결과: `…_분반1_A조_어민선_이어붙임.mp4`. 원본은 지우지 않고 `_조각원본`(주 녹화 조각) · `_예비녹화원본`(같은 폴더에 있던 예비 녹화) 폴더로 옮깁니다.
  - 주·예비 녹화 모두 없는 곳이 있으면 몇 초인지 알려 줍니다.
- **처음 한 번 설치**(녹화 PC):
  1. **ffmpeg 설치**: 「터미널」 앱(Spotlight에서 `터미널`) → Homebrew가 없으면 https://brew.sh 첫 화면의 설치 명령을 붙여 넣고 엔터(맥 암호 입력) → 끝나면 `brew install ffmpeg` 엔터(몇 분).
  2. **합치기 프로그램 받기**: 터미널에 아래 두 줄을 붙여 넣고 엔터 → 바탕화면에 「녹화 조각 합치기.command」가 생깁니다.
     ```
     curl -fsSL https://mentoring.kartsproject.com/a/tools/merge-parts.command -o ~/Desktop/"녹화 조각 합치기.command"
     chmod +x ~/Desktop/"녹화 조각 합치기.command"
     ```
- **회차가 끝날 때마다**:
  1. 녹화를 끄고(스위치 끄기 → 저장 완료) 몇 초 기다립니다.
  2. 예비 녹화 PC의 녹화 폴더(파일 전부 + `_녹화기록_…_예비_….tsv`)를 주 녹화 PC로 옮깁니다 — 구글 드라이브 동기화 중이면 드라이브에서 내려받은 폴더를 쓰면 됩니다. 주 녹화 폴더에 함께 넣어도 되고, 따로 둬도 됩니다.
  3. 바탕화면의 「녹화 조각 합치기」를 **더블클릭** → 주 녹화 폴더 고르기 → 예비 녹화가 따로 있으면 「예비 녹화 폴더 고르기」.
  4. 창에 ✔가 나오면 끝. 엔터를 누르면 창이 닫힙니다.
  - 처음 열 때 「확인되지 않은 개발자」가 뜨면: 파일을 **오른쪽 클릭 › 열기 › 열기**. 폴더 접근을 물으면 「허용」.

**구글 드라이브에 바로 올리기(권장 방법)**: 녹화 PC에 Google Drive 데스크톱 앱을 설치하고, 녹화 폴더를 **환경설정 › 내 Mac(내 노트북) › 폴더 추가 › Google Drive와 동기화**로 등록합니다. PC에 먼저 저장되고 드라이브 「컴퓨터」 항목으로 자동 업로드됩니다. 휴대폰 테더링 중에는 동기화를 일시중지했다가 끝난 뒤 와이파이에서 올리세요.

### 멘토 (`m.html`)
- 위 띠 **오른쪽 위 「나가기」**(두 번 누름 — 「정말 나가기」), 아래 **마이크·카메라 켜고 끄기** 버튼.
- 입장하면 카메라·마이크가 켜집니다. 말하는 사람 칸에는 **초록 후광과 왼쪽 아래 소리 아이콘**이 보입니다. 화면은 **위 멘토 · 아래 학생**(명단 자리 고정, 미참여자는 검은 칸에 이름). 위 띠 오른쪽에 마침까지 남은 시간이 참고용으로 작게 보입니다(깜빡임·알림음 없음).
- 칸을 누르면 **그 방 모두에게 크게 보기**(작품 설명할 때). 「크게 보기 끄기」로 해제.
- 칸 위 도구: **마이크 끄기**(학생), **손 내리기**, **사진 내리기**.
- 「작품 보여주기」: 화면 공유 · 후면 카메라 · 사진 올리기(멘토도 가능).

### 학생 (`index.html`)
- 이름·생년월일 → 녹화 안내 동의 → 카메라·마이크 확인 → 입장.
- 화면은 **위 멘토 · 아래 학생**(전체에서는 멘토 영역 가로 2 × 세로 2 크게, 학생 영역 가로 6 × 세로 2 작게, 두 영역을 바탕색으로 구분 / 작품 공유·사진은 멘토 영역 가운데에 크게). **전체에서는 마이크가 꺼진 채** 들어가고, 분반으로 옮기면 **자동으로 켜집니다**(직접 켜고 끌 수 있음).
- **손들기**, **작품 보여주기**: 화면 공유(PC) · 후면 카메라로 바꾸기(휴대폰) · 사진 올리기(긴 변 2000px로 줄여 올림, 드라이브에 보관·공개 링크 없음).
- 아래 **마이크·카메라 켜고 끄기** 버튼, **오른쪽 위 「나가기」**(두 번 누름).
- 새로고침해도 다시 로그인하지 않고 들어옵니다.

## 6. 권장 환경

| 구분 | 권장 |
|---|---|
| 녹화 PC | 크롬. 최근 세대 CPU(예: 맥북프로 M3 Pro급), 메모리 16GB 이상, 저장 공간 50GB 이상 여유. 전원 연결·잠자기 방지 |
| 녹화 PC 인터넷 | 받기 **50Mbps 이상**, 유선 권장(5G 테더링 가능 — 테더링 제공량 확인, 2시간 회차 약 15~20GB) |
| 운영진·연구원·멘토 | 받기 20Mbps / 보내기 5Mbps 이상 |
| 학생 | PC·노트북 권장(휴대폰 가능), 받기 10~20Mbps / 보내기 3Mbps 이상, 5GHz 와이파이 |

## 7. 문제 해결

| 증상 | 확인 |
|---|---|
| 「영상 연결에 실패했습니다」가 반복 | 스크립트 속성 CF_SFU_APP_ID/TOKEN, 학교 망이면 TURN 키 추가 |
| 입장이 안 됨(명단) | 시트 「명단」 회차·이름(띄어쓰기 무시) 확인, 1분 뒤 다시 |
| 회차가 다르게 잡힘 | 시트 「회차」 날짜 형식 `2026-11-21`, 또는 「직접 입력」 |
| 사진이 안 보임 | Apps Script를 setup 실행 후 다시 배포했는지(드라이브 권한) |
| 영상이 멈추고 소리만 남 | Code.gs Ver.1.3으로 바꿨는지(필수). 멈춘 화면은 9초 안에 자동으로 다시 받아옵니다. 학생은 5GHz 와이파이·PC 권장 |
| 녹화 파일이 같은 단계에서 여러 개 | 정상입니다(이어 녹화). 끝난 뒤 「녹화 조각 합치기」로 한 파일로 |
| 녹화 영상이 멈춤 | 녹화 PC의 운영 창을 **앞에 띄워 두세요**(최소화·다른 탭으로 가리면 경고가 뜸). 녹화 PC는 다른 프로그램을 닫고 전원 연결 |
