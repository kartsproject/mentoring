# 미술 온라인 멘토링 시스템 — 구상안 (Ver.1.0, 2026-11-17)

무용 온라인 멘토링 시스템(Ver.2.2)의 틀을 이어받되, 미술 멘토링 진행 방식에 맞게 다시 짠 구상입니다.

## 1. 진행 방식과 무용과의 차이

| 구분 | 무용 (구축 완료) | 미술 (이번 구상) |
|---|---|---|
| 형태 | 멘토 1 : 학생 1, 10분씩 차례로 | 멘토 3~4명 + 학생 10여 명이 함께 |
| 흐름 | 대기실 → 차례 호출 → 1:1 → 다음 학생 | **전체 → 분반(멘토 1 + 학생 3~4) → 전체로 모여 마무리** |
| 대기실·순서 입장 | 있음(대기 순서, 호출, 다음 학생 준비) | **없음** — 들어오면 바로 지금 진행 중인 방으로 |
| 채팅 | 대기실 채팅·공지 | **없음** — 대신 화면 위 공지 띄우기, 손들기 |
| 동시 접속 | 2명 영상(+운영진 보기) | 최대 약 16명 영상 + 운영진·연구원 |
| 녹화 | 학생별 파일 | **단계·조별 파일**(전체 1·조별 4·전체 2) |

진행 흐름(한 회차):

```
[입장·장치 점검] → [전체 멘토링] → [분반: 1조 2조 3조 4조 동시 진행] → [전체로 모여 마무리] → [종료]
                      ↑ 운영진이 단계 버튼으로 전환(모두 자동 이동, 1분 전 예고)
```

## 2. 핵심 기술 결정 — 영상 중계 방식

무용은 브라우저끼리 직접 연결(P2P)했습니다. 2~3명이면 충분하지만, **16명이 서로 모두 연결하면** 학생 휴대폰·노트북이 15개 영상을 동시에 보내고 받아야 해서 끊기거나 멈춥니다.

**제안: Cloudflare Realtime SFU(영상 중계 서버) 사용**
- 각자 영상을 **한 번만** 올리면 Cloudflare가 필요한 사람에게 나눠 줍니다. 분반·전체 전환은 "누구 영상을 받을지"만 바꾸면 되어 빠릅니다(올리는 연결은 그대로).
- 이미 무용용으로 쓰는 **같은 Cloudflare 계정·Realtime**에서 앱만 하나 더 만들면 됩니다(결제카드 등록 완료 상태).
- 비용: 매달 **1,000GB까지 무료**(TURN과 합산), 넘으면 GB당 $0.05. 올리는 쪽(학생→Cloudflare)은 늘 무료.
- 사용량 추정: 한 회차(약 2시간 30분, 16명 + 녹화 PC 2대) ≈ 70GB 안팎 → 3회차 약 210GB로 **무료 범위 안**. 무용 TURN 사용량을 더해도 여유 있음.
- 화질 자동 조절(simulcast): 작은 칸으로 볼 때는 낮은 화질, 크게 볼 때는 높은 화질을 받아 휴대폰 부담을 줄임.

연결 구조:

```
학생·멘토·운영진 브라우저 ──(영상 1번 올림)──▶ Cloudflare Realtime SFU ──(필요한 영상만)──▶ 각 브라우저·녹화 PC
           │                                                ▲
           └──(입장·단계·분반 상태)──▶ Apps Script 관문 ──(앱 비밀키로 영상 연결 요청 대행)
```

- 진행 상태(지금 단계, 조 배정, 누가 어느 방, 공지, 타이머)는 무용과 같이 **Apps Script + 구글 시트**에서 관리합니다.
- Cloudflare 앱 비밀키는 Apps Script 스크립트 속성에만 둡니다(웹 페이지·저장소에 노출 안 됨).
- Apps Script를 거치면 연결 요청 한 번에 0.5~1.5초가 걸립니다. 전환이 느리게 느껴지면 2단계에서 Cloudflare Worker(무료)로 바꿀 수 있게 구조를 나눠 둡니다.

## 3. 접속 주체와 화면

### 학생
1. 이름 + 생년월일로 본인 확인(무용과 동일, 회차는 날짜로 자동) → 유의사항 카드 → 카메라·마이크 점검
2. **바로 지금 진행 중인 방으로 입장** — 전체면 전체 방, 분반 중이면 자기 조 방
3. 전체 방: 멘토들 크게 + 학생들 작은 칸. 들어올 때 마이크는 꺼짐, **손들기** 버튼
4. 분반 전환: 화면에 "3초 뒤 2조로 이동합니다 · 멘토 ○○○" 안내 후 자동 이동, 조 안에서는 마이크 켜짐
5. **작품 보여주기**
   - PC: 화면 공유(디지털 작업, 포트폴리오 파일)
   - 휴대폰·태블릿: 후면 카메라로 바꾸기(실물 작품 비추기)
   - 사진 올리기: 고화질 사진 한 장을 올려 조 화면에 크게 띄움(원본은 드라이브 보관)

### 멘토
- 멘토 코드 + 이름으로 입장, 자기 담당 조가 자동으로 정해짐
- 전체 방: 멘토 4명이 함께 진행, 한 사람 크게 보기(발표자 고정)
- 분반 방: 학생 3~4명과 그룹 멘토링 — 학생 한 명 크게 보기, 학생이 올린 작품 사진 크게 보기, 학생 마이크 끄기 요청
- 남은 시간 크게 표시, 단계 종료 1분 전 경고(무용 멘토 화면과 같은 방식)

### 운영진 — 진행판
- **단계 버튼**: [전체 시작] [분반 시작] [전체로 모으기] [마치기] — 누르면 모두 자동 이동, "1분 뒤 전체로 모입니다" 예고를 먼저 띄울 수 있음
- **분반 배정판**: 시트의 기본 조를 불러오고, 그날 결석·추가에 맞춰 학생 카드를 끌어다 조 이동(분반 중에도 이동 가능)
- **조별 미니 화면**: 4개 조를 한 화면에서 보고, 하나를 골라 소리 듣기(엿듣기). 스페이스를 누르고 있는 동안 그 조에 말하기(무용과 같은 누르고 말하기)
- **공지 띄우기**: 모든 방(또는 특정 조) 화면 위에 공지 띄우기 — 채팅 대신
- **접속 현황**: 미접속 학생 표시와 학생·보호자 연락처(전화·복사), 손든 학생 표시
- **단계별 타이머**: 회차 시간표(전체 1 · 분반 · 전체 2)에 맞춰 남은 시간과 알림

### 연구원
- 관찰 전용: 조를 골라 보고 듣기, 필요하면 누르고 말하기
- (선택) 관찰 메모: 시각이 자동으로 찍히는 짧은 메모를 시트에 저장 → 보고서 작성에 활용

## 4. 녹화

- 무용 Ver.2.2의 녹화 엔진을 그대로 씁니다: **FHD(1920×1080)**, 폴더 자동 저장, 예비 사본·창 꺼짐 복구, 소리 막힘 대응, 멈춤 감지·경고.
- 파일은 **단계·조별**로 나눠 저장:
  - `261205_1400_미술_2회차_전체1.mp4`
  - `261205_1430_미술_2회차_1조_멘토이름.mp4` … `4조`
  - `261205_1530_미술_2회차_전체2.mp4`
  - 그 밖의 시간(시작 전·전환 중)은 `_대기` 파일
- 화면 구성: 전체는 멘토 크게 + 학생 바둑판, 조는 멘토 + 학생 3~4명 바둑판, 작품 사진·화면 공유는 크게
- 분반 중에는 4개 조를 **동시에** 녹화해야 하므로 PC 부담이 큽니다 → **녹화 PC 2대 권장**(예: A는 전체 + 1·2조, B는 전체 + 3·4조). 전체 단계는 두 대 모두 녹화해 서로 예비본

## 5. 시트 구성(미술 전용 새 시트)

| 탭 | 열 |
|---|---|
| 명단 | 회차 · 이름 · 생년월일 · 기본 조 · 학생 연락처 · 보호자 연락처 |
| 멘토 | 회차 · 멘토 이름 · 담당 조 |
| 회차 | 회차 · 날짜 · 전체1 시작 · 분반 시작 · 전체2 시작 · 마침 |
| 기록 | 시각 · 회차 · 구분(입장·단계 전환·조 이동·공지) · 이름 · 내용 |
| 관찰 메모(선택) | 시각 · 회차 · 단계·조 · 연구원 · 메모 |

## 7. 개발 순서(안)

1. Cloudflare SFU 앱 만들기(사용자) → 16명 동시 접속 시험 페이지로 연결·화질·전환 속도 확인
2. 관문(시트·Apps Script): 회차·명단·멘토·조 배정·단계 상태
3. 학생·멘토 화면(전체·분반 자동 이동, 손들기, 작품 보여주기)
4. 운영 진행판(단계 버튼, 분반 배정판, 조별 미니 화면, 공지, 접속 현황)
5. 녹화(단계·조별 파일, 녹화 PC 2대 나눠 맡기)
6. 리허설: 운영진·연구원이 학생 역할로 휴대폰·노트북 섞어 10명 이상 접속

## 8. 정해 주셔야 할 것

1. 다음 미술 멘토링 날짜와 회차별 시간표(전체·분반 시간)
2. 조 배정: 시트에 미리 정해 두는 방식 + 당일 운영진이 조정 — 이대로 괜찮은지
3. 학생 기기: PC·노트북 권장으로 안내할지, 휴대폰도 똑같이 지원할지
4. 작품 보여주기 범위: 화면 공유 · 후면 카메라 · 사진 올리기 중 꼭 필요한 것
5. 녹화 PC를 몇 대 둘 수 있는지(2대 권장)
6. 연구원 관찰 메모 기능 필요 여부

## 9. 주의할 점

- 학생 기기 성능·회선 차이가 큼 → 자동 화질 조절, 영상 끊김 시 "음성만" 자동 전환, 연결 상태 표시
- Cloudflare 무료 사용량은 대시보드에서 월별 확인(넘어도 GB당 $0.05 소액이지만 결제카드가 등록되어 있으므로 확인 필요)
- 미성년 학생 영상 녹화 → 무용과 같이 입장 화면에서 녹화 동의 확인
