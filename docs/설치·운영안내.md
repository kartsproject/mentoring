# 무용 온라인 멘토링 시스템 — 설치·운영 안내 (Ver.2.1, 2026-11-16)

ZOOM과 기존 웹 대기실(b_apply)을 대신하는 **한 시스템**입니다. 학생은 대기실에서 기다리다 차례가 되면 그 화면에서 바로 멘토링을 받습니다. 별도 영상 서비스나 유료 서비스는 쓰지 않습니다(중계 서버는 Cloudflare 무료 한도).

| 접속 주체 | 하는 일 |
|---|---|
| **학생** | 이름+생년월일 입장 → 유의사항 카드 → 카메라 확인 → 대기실(순서·채팅·공지) → 차례가 되면 자동으로 멘토링 화면 |
| **멘토** | 학생 화면을 크게 보며 멘토링. 큰 카운트다운·1분 전 경고 |
| **운영진(여러 명)** | 진행(시작·다음·종료), 녹화, 학생 카드·시간 알림·연락처, 대기실 채팅·공지, 예비 ZOOM |
| **연구원** | 보기 + 멘토링 전 「화면 등장」으로 멘토와 논의(진행 조작·녹화·채팅 보내기는 없음) |

## 3. 처음 설정 / Ver.2.0으로 올릴 때

### 3-1. Code.gs 바꾸기
1. 시트 「무용 온라인멘토링」 → 확장 프로그램 → Apps Script → `Code.gs` 내용을 모두 지우고 새 코드를 붙여넣기 → 💾 저장
2. 함수 **`setup`** 선택 → 실행. 로그에 코드 3개와 `명단: test회차 n명 …`이 나오면 됩니다.
   - 「명단」 머리글이 새 형식으로 바뀌고(기존 내용은 유지), 「회차」「채팅」 탭이 생깁니다.
3. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** (「새 배포」 금지: 주소가 바뀜)

### 3-2. 시트 「명단」 (회차별 학생)

| 회차 | 순서 | 이름 | 생년월일 | 대기실 접속 | 멘토링 시간 | 학생 연락처 | 보호자 연락처 |
|---|---|---|---|---|---|---|---|
| 3 | 1 | 홍길동 | 20140505 | 17:20 | 17:30 – 17:40 | 010-1234-5678 | 010-9876-5432 |

- 기존 「무용분야 심화멘토링 신청」 시트의 명단(이름·생년월일·연락처)과 분반 명단(시간)을 그대로 복사해 넣으면 됩니다. 이름에는 `발레_`를 붙이지 않습니다.
- **생년월일**: 8자리. 학생은 8자리 또는 뒤 6자리로 들어올 수 있습니다. 비워 두면 이름만으로 입장(리허설용).
- **대기실 접속**: 비우면 멘토링 시작 10분 전으로 계산합니다. **멘토링 시간**: `17:30 – 17:40` 또는 `17:30`(끝은 10분 뒤로 계산).
- 연락처는 **운영진 화면에만** 보입니다(학생·멘토·연구원 화면에는 나오지 않음).
- 학생이 여러 회차에 있으면 오늘 회차 → 가장 가까운 다음 회차 순서로 자동 입장합니다.

### 3-3. 시트 「회차」

| 회차 | 날짜 | 멘토 | 휴식(몇 번째 학생 뒤) |
|---|---|---|---|
| 3 | 2026-12-06 | 정은영 | 5 |

- 날짜가 있어야 그날 **시간 알림**이 작동합니다. `test`(리허설)는 날짜를 비워 두면 늘 오늘로 봅니다.
- 휴식 칸의 숫자 뒤에 운영 화면 학생 목록에 「— 휴식 —」이 표시됩니다.

### 3-4. 이미 끝낸 설정(그대로 유지)
GitHub Pages·도메인(`mentoring.kartsproject.com`), Cloudflare TURN 키, 웹앱 주소(`config.js`)는 바꿀 것이 없습니다.

## 4. 학생 화면 (기존 웹 대기실 기능 포함)
1. **본인 확인**: 이름 + 생년월일 + 녹화 동의
2. **유의사항 카드뉴스**(처음 한 번 필수, 대기실의 「유의사항」으로 다시 보기): 카메라·마이크 ON / 화면 배치 / 10분 전 접속 / 대기실 안내(차례가 되면 자동 시작) / 참관 제한 / 시간 안내 / 녹화 안내
3. **카메라·마이크 확인**
4. **대기실(한 화면)**: 상태(대기 중 · 내 앞 n명 · 현재 n번 진행 중 → 「다음 차례입니다」 → 완료), 내 순서·대기실/멘토링 시각·날짜·멘토, 연결 점검·멘토 연결 준비 표시, 내 화면 미리보기·마이크 막대, **대기실 채팅**(운영진은 「운영진」으로 표시), **상단 고정 공지**, 지금 접속 인원
5. 차례가 되면 **알림음·진동·제목 깜빡임과 함께 자동으로 멘토링 화면**(카메라·마이크 자동 켜짐). 끝나면 대기실로 돌아와 「멘토링이 끝났습니다」
- 새로고침해도 같은 탭이면 다시 입력하지 않고 카메라 확인부터. 「나가기」(두 번 누름)로 처음부터.
- 카카오톡에서 열면 기본 브라우저로 다시 엽니다. 확대·축소 막음(휴대폰).

## 5. 운영 화면 (기존 대기실 운영 기능 포함)

### 화면 구성
- 넓은 화면(1500px 이상): **화면·녹화 | 학생 | 채팅** 3단. 중간 크기: 화면 + [학생/채팅] 탭. 휴대폰: [화면/학생/채팅] 탭.
- 위쪽: **회차 탭**(1회차·2회차·3회차·리허설), 화면 등장, 이 PC에서 녹화, 영상 소리, 알림음, 운영 순서, 알림 미리보기, **대기실 창 열기**, 나가기

### 대기실 창 (녹화 담당이 창 두 개로 운영)
- 녹화 창의 **「대기실 창 열기」**(또는 운영 Hub의 「대기실 운영 창」 주소로 바로 열고 로그인) → 새 창에 **학생·알림·채팅·공지만** 뜹니다(영상·녹화 없음, 로그인 이어받음). 녹화 창 옆에 띄워 두고 함께 쓰면 됩니다.
- 대기실 창에서 [시작]·[종료]를 눌러도 녹화 창이 자동으로 녹화·저장합니다.
- 팝업이 막히면 주소창 오른쪽 팝업 차단 아이콘에서 「허용」.

### 학생 카드
- **카드 색**: 접속 중(초록) / 미접속·나감(회색, 「n초 전」) / 멘토링 중(빨강 테두리) / 완료(흐리게)
- 표시: 순서, 대기실·멘토링 시각, 연결 점검 결과(연결 확인·중계 연결·연결 실패), 카메라·마이크 꺼짐, 휴대폰, ZOOM 안내 중
- **연락처**: 학생·보호자 번호(누르면 전화, [복사])
- 버튼: [시작] / [종료] / [ZOOM] / [재점검] / [완료 취소]. 카드의 이름을 누르면 채팅에 `@이름`이 붙습니다.

### 시간 알림 (그 회차 날짜에만)
| 알림 | 언제 | 하는 일 |
|---|---|---|
| ⏰ **멘토링 시간** | 학생의 멘토링 시작 시각이 지났는데 시작 안 함 | 빨간 알림 + [⏰ 시작] 깜빡임 + 알림음(누를 때까지 30초마다) + 데스크톱 알림 |
| ⚠ **미접속** | 대기실 접속 시각이 지났는데 접속 안 함·끊김 | 연락처 표시 → **채팅 말고 전화**. [확인함]으로 닫기, 접속하면 자동으로 사라짐 |
| 🎯 다음 차례 | 다음 순서 학생이 접속해 있음 | 멘토와 미리 연결 상태 표시 |
| 🕐 곧 차례 | 시작 1분 전 | 안내 |
- 제목 표시줄 깜빡임, 좁은 화면에서는 [학생] 탭에 ⚠ 표시. 처음 들어올 때 브라우저가 알림 허용을 물으면 「허용」.
- **🧪 알림 미리보기**: 이 창의 시계만 그 시각으로 돌려 알림을 리허설합니다(학생 화면·시트에는 영향 없음).
- **📋 운영 순서**: 당일 순서를 명단 시각에 맞춰 보여 줍니다.

### 대기실 채팅·공지
- 채팅: 학생 전체와 운영진이 함께 보는 방. 빠른 문구 버튼, `@이름`, 메시지별 [×] 지우기(두 번 누름), **🗑 채팅 지우기**(전체, 두 번 누름). 다른 운영진 메시지는 이름과 함께 표시. 학생 새 메시지 알림음, 좁은 화면에서 안 읽은 개수.
- **📢 상단 고정 공지**: 학생 채팅창 위에 고정(최근 3개 표시). [전체 보내기] 두 번 눌러 확인, 「공지 모두 내리기」.
- 모든 채팅·공지는 시트 「채팅」에 남습니다(화면에서 지워도 기록은 남음).
- **회차 초기화**: 진행 상태·채팅·공지를 비웁니다(리허설 후, 두 번 누름).

## 6. 당일 운영 순서
1. **첫 학생 대기실 접속 20분 전**: 운영진 입장. 녹화 담당은 「이 PC에서 녹화」 켜고 저장 폴더 확인 → 「대기실 창 열기」로 대기실 창을 옆에 띄움. 「예비 ZOOM 링크」 저장.
2. 멘토 입장(멘토 코드). 연구원·운영진은 「화면 등장」으로 사전 논의(스페이스 누르고 말하기).
3. 학생이 대기실에 들어오면 녹화 PC가 자동으로 연결 점검 → 카드 확인. 실패는 [ZOOM].
4. 시작 시각 → [시작](또는 「다음: ○○ 시작」). 다음 학생은 미리 연결돼 있어 **1초 안에** 바뀌고, 앞 학생 녹화는 자동 저장.
5. 미접속 알림 → **전화**. 지연되면 상단 고정 공지.
6. 마지막 학생 [이 학생 종료] 두 번 → 녹화 저장 확인.

## 7. 그 밖의 기능 (Ver.1.x에서 이어짐)
- **멘토 화면**: 오른쪽 위 큰 카운트다운, 8분 뒤 질의응답, 1분 전 테두리 깜빡임·가운데 알림·알림음, 시간 초과 표시
- **화면 등장**(연구원·운영진, 멘토링 전·최대 3명): 기본 마이크 꺼짐, **스페이스 누르는 동안만 말하기**(휴대폰은 「누르고 말하기」), 「마이크 항상 켜짐」 전환. 멘토링 시작 시 자동으로 내려감. 이어폰 권장.
- **녹화**: **FHD 1920×1080**(창 크기와 상관없이 이 크기로 저장, 영상 6Mbps — 10분에 약 450MB), 두 사람 화면 좌우 합성 + 두 음성, 학생별 파일 `3회차_01_이름_1732.mp4`, 정한 폴더에 **창 없이 자동 저장**(쓰는 중 `…crswap`). 바탕화면·다운로드 폴더 자체가 아닌 그 **안의 새 폴더**를 고르세요.
- **빠른 전환**: 연결된 사람끼리는 데이터 통로로 시작·종료를 바로 전달(서버에도 기록). 대기실 창(영상 없음)에서 누르면 서버를 거쳐 1~2초.
- **중계 서버**: Cloudflare TURN(월 1,000GB 무료). 키가 없으면 구글 STUN만.
