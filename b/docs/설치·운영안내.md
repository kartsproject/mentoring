# 무용 온라인 멘토링 시스템 — 설치·운영 안내 (Ver.2.14, 2026-11-19)

ZOOM과 기존 웹 대기실(b_apply)을 대신하는 **한 시스템**입니다. 학생은 대기실에서 기다리다 차례가 되면 그 화면에서 바로 멘토링을 받습니다. 별도 영상 서비스나 유료 서비스는 쓰지 않습니다(중계 서버는 Cloudflare 무료 한도).

| 접속 주체 | 하는 일 |
|---|---|
| **학생** | 이름+생년월일 입장 → 카메라 확인 → **대기실 화상**(다른 학생·운영진과 얼굴 보며 대기, 순서·공지) → 차례가 되면 자동으로 멘토링실 → 끝나면 안내 후 바로 퇴장 |
| **멘토** | 학생 화면을 크게 보며 멘토링. 큰 카운트다운·1분 전 경고 |
| **운영진(여러 명)** | 진행(시작·다음·종료), 녹화(멘토링실만), **대기실 칸**(학생 접속·연락처·호출 알림·미접속 빨간 테두리·멘토링 시간 [시작] 깜빡임), **대기실 화상 진행**(듣기·스페이스바로 말하기·학생 마이크 끄기/모두 끄기·켜기)·공지, 예비 ZOOM |
| **연구원** | 멘토링실 보기 + **대기실 화상**(듣기·누르고 말하기·내 카메라). 진행 조작·녹화는 없음 |

## 1. 주소
- 학생·멘토·운영진 모두 **회차를 넣지 않아도** 시트 「회차」의 날짜에 맞춰 자동으로 들어갑니다(오늘 → 가장 가까운 다음 회차 → 가장 최근 회차). 리허설은 주소 끝에 `?r=test`를 붙이거나 입장 화면의 「직접 입력」에 `test`. **이 기능은 Code.gs Ver.2.1이 필요합니다.**

| 누가 | 주소 |
|---|---|
| 학생 | `https://mentoring.kartsproject.com/b/` (회차는 명단에서 자동으로 찾음) |
| 멘토 | `https://mentoring.kartsproject.com/b/m.html` + 멘토 코드 |
| 운영진·연구원 | `https://mentoring.kartsproject.com/b/o.html` + 운영진/연구원 코드 |
| 대기실 창(운영) | 운영 화면의 **「대기실 창 열기」** 또는 `…/b/o.html?mode=room` |
| 리허설 | 주소 끝에 `?r=test` (학생 `…/b/?r=test`) |
| 분야 선택 | `https://mentoring.kartsproject.com/` — 무용(b)·미술(a) 고르기. 예전 주소(`/mentor.html`, `/ops.html`, `/?r=…`)는 무용(b)으로 자동 이동 |

## 0-7. Ver.2.14 — 대기실 소리 ↔ 멘토링실 소리 하나만 (2026-11-19)
- 대기실 머리 줄 **「대기실 소리 켬」** → 대기실 소리가 들리고 **멘토링실 소리는 꺼집니다.**
- **「대기실 소리 끔」**(처음 상태) → **멘토링실 소리가 들리고** 대기실 소리는 꺼집니다.
- 녹화 창과 「대기실 창」을 나눠 쓸 때도(같은 PC·같은 크롬) 두 창이 함께 바뀝니다. 녹화 창의 「영상 소리 켬/끔」도 같은 스위치입니다.
- 스피커로 듣는 소리만 바뀌고, **녹화 파일의 소리(멘토·학생)는 그대로 녹음**됩니다.
- Code.gs는 바꿀 것 없음(Ver.2.4 그대로).

## 0-6. Ver.2.13 — 녹화 준비 창 「건너뛰기」 (2026-11-19)
- 운영 화면에 들어올 때 뜨는 「녹화 준비」 창에 **「건너뛰기 — 이 PC에서는 녹화하지 않음」** 버튼을 넣었습니다.
  - 건너뛰면 그 PC에서는 **멘토링도 녹화되지 않습니다.** 녹화 PC가 따로 있을 때(보조 운영진·노트북 등)만 쓰세요.
  - 녹화 상자에 「이 PC는 녹화하지 않습니다」와 함께 **누구 PC에서 녹화 중인지** 표시됩니다. 녹화하는 PC가 하나도 없으면 「녹화하는 PC가 없습니다!」로 바뀝니다.
  - 마음이 바뀌면 녹화 상자의 **「녹화 시작」**(또는 「폴더 정하기」)을 누르면 녹화 준비 창이 다시 뜹니다.
- Code.gs는 바꿀 것 없음(Ver.2.4 그대로).

## 0-5. Ver.2.12 — 운영 화면 알림음 없앰 (2026-11-19)
- 운영 화면·대기실 창의 **알림음을 모두 없앴습니다**(멘토링 시간 30초마다 울리던 소리, 종료 1분 전 소리 포함). 위쪽 「알림음」 버튼도 숨겼습니다.
- 남은 것: 대기실 칸의 [시작] 빨간 깜빡임·빨간 테두리, 제목 표시줄 깜빡임, 진행 시간 막대(1분 전 빨강).
- **녹화가 안 될 때의 경고음만** 그대로 둡니다(녹화 상자 빨강 「녹화 안 됨!」과 함께 20초마다) — 녹화 사고를 놓치지 않도록.
- 멘토 화면의 1분 전 알림음, 학생 화면의 「띵동」 호출음은 그대로입니다.

## 0-4. Ver.2.11 — 학생 4명씩 3줄 · 빨간 테두리 잘림 고침 (2026-11-19)
- 대기실 학생 칸을 **한 줄에 4명씩**(12명이면 4명 × 3줄) 놓습니다. 위쪽 운영진·연구원은 그대로 가로 한 줄.
- 미접속 **빨간 테두리**(와 멘토링 중 노란 테두리)를 칸 **안쪽**에 그려, 맨 왼쪽·오른쪽 칸에서도 잘리지 않게 했습니다.
- Code.gs는 바꿀 것 없음(Ver.2.4 그대로).

## 0-3. Ver.2.10 — 스페이스바로 말하기 · 학생 마이크 모두 끄기/켜기 · 5명씩 배치 · 녹화는 「녹화 시작」부터 (2026-11-19)
- **녹화가 바뀌었습니다.**
  - 운영 화면에 접속해도 **자동으로 녹화하지 않습니다.** 접속하면 「녹화 준비」 창에서 **저장 폴더만** 고릅니다.
  - **멘토링이 진행되는 동안은 항상 자동 녹화**합니다(학생별 파일 `…_02_이름.webm`). 멘토링 중에는 「녹화 중지」가 잠겨 있고, 학생이 끝나면 자동 저장됩니다.
  - 멘토링 사이(대기) 시간은 **운영자가 「녹화 시작」을 눌렀을 때만** 「대기」 파일로 녹화합니다. 「녹화 중지·저장」을 누르면 대기 녹화만 멈추고, 다음 멘토링은 다시 자동 녹화됩니다.
  - 녹화 상자에 「녹화 대기 — 멘토링이 시작되면 학생별로 자동 녹화」가 보이면 정상입니다.
  - 저장 폴더를 고르지 않으면(「녹화 준비」 창을 닫지 않으면) 녹화되지 않습니다. 녹화 PC에서는 꼭 폴더를 고르세요.
- **누르고 말하기 = 키보드 스페이스바**: 운영진·연구원은 스페이스바를 누르고 있는 동안 대기실에 말합니다(떼면 꺼짐). 글자 입력 칸(공지 등)에 커서가 있을 때는 작동하지 않습니다.
- **학생 마이크 모두 끄기 / 모두 켜기**(운영진만): 대기실 머리 줄 버튼.
  - 끄면 대기실의 모든 학생 마이크가 꺼지고, 학생은 직접 켤 수 없습니다(「운영진이 꺼 둠」). 나중에 들어온 학생도 꺼진 채로 들어옵니다.
  - 다시 「모두 켜기」를 누르면 학생 마이크가 모두 켜집니다. 멘토링실에 들어간 학생은 영향 없이 마이크가 켜집니다.
  - 시트 「기록」에 「학생 마이크 모두 끄기/켜기」가 남습니다.
- **대기실 배치**: (Ver.2.11에서 한 줄 4명으로 바뀜) 학생은 한 줄에 5명씩(10명이면 5명 × 2줄), 위쪽 운영진·연구원은 **가로 한 줄**로만. 칸이 작아지면(노트북 반쪽 화면) 글자·버튼을 줄여 다 보이게 합니다. 학생 휴대폰처럼 좁은 화면은 크기에 맞춰 자동 배치.
- **Code.gs Ver.2.4** 필요(학생 마이크 모두 끄기/켜기). 아래 3-1 순서대로 붙여넣기 → 저장 → **배포 관리 → 새 버전**. `setup`은 다시 실행하지 않아도 됩니다.

## 0-2. Ver.2.9 — 알림 팝업 없음 · 대기실 위 운영진 고정 · 멘토링실은 두 사람만 (2026-11-19)

  - 대신 대기실 칸에서 봅니다: 멘토링 시간이 된 학생 → 칸의 **[시작] 빨간 깜빡임**, 접속 시각이 지난 미접속 학생 → **빨간 테두리**.

- **멘토링실(왼쪽) 화면에는 멘토와 지금 멘토링 중인 학생만** 나옵니다.

  - 다음 학생 **미리 연결은 그대로** 되어 있어 [시작]을 누르면 1초 안에 바뀝니다(화면에만 안 보임).

## 0-1. Ver.2.8 — 운영 화면 반반 · 대기실 칸이 학생 카드 대신 (2026-11-19)
- 운영 화면을 **반으로 나눠 왼쪽 멘토링실 · 오른쪽 대기실**(좁은 화면은 [화면]/[대기실] 탭, 대기실 창은 대기실만 크게).
- **학생 카드(접속 현황 카드·합계 카드)는 모두 없앴습니다.** 대기실 화상 칸이 대신합니다.
- 대기실 화면: **위 운영진(카메라를 켜거나 말한 사람) · 아래 학생**(명단 순서로 자리 고정). 학생 화면도 같은 배치(위 운영진 · 아래 나와 다른 학생).
- 학생 칸:
  - **접속한 학생** → 카메라 화면. 아래 줄에 **「n번 · 멘토링 12:05–12:15」 + [🔔 알림] + [시작] + [⋯](ZOOM 안내·연결 재점검)**. 멘토링 시간이 되면 [시작]이 빨갛게 깜빡임.
  - **[🔔 알림]**: 누르면 그 학생 화면에서 **「띵동」 소리 두 번 + 진동 + 「운영진이 부르고 있어요」 안내**(시트 「기록」에 「학생 호출」 남음).
  - **접속 안 한 학생** → 학생 정보 칸(순서·이름·미접속/몇 분 전 나감·대기실·멘토링 시각·학생/보호자 전화(누르면 전화)·[시작]·[ZOOM]).
  - **대기실 접속 시각이 지났는데 접속 안 함 → 칸 테두리 빨강**(「대기실 접속 시각 지남」). 예전 위쪽 「미접속」 알림 팝업은 이것으로 바뀌어 더는 뜨지 않습니다.
  - 멘토링 중인 학생은 노란 테두리 「멘토링실에서 진행 중」 + [종료], 끝난 학생은 흐리게 「완료 hh:mm」 + [완료 취소].
- 머리 줄: 「대기실 · 접속 n / 명단 m명 · 완료 k」, 대기실 소리·누르고 말하기·마이크 켜 두기·내 카메라·**설정·ZOOM**(예비 ZOOM 링크·접속 중인 운영진·회차 초기화).
- (Ver.2.9에서 알림 팝업은 모두 없앰 — 위 0-2 참고.)
- **Code.gs Ver.2.3** 필요(알림 「띵동」 기능). 2.2를 아직 안 넣었다면 2.3만 넣으면 됩니다(스크립트 속성 `CF_SFU_APP_ID`·`CF_SFU_APP_TOKEN`은 아래 Ver.2.7 안내대로).

## 0. Ver.2.7 — 멘토링실 / 대기실 화상 (2026-11-19)
- **멘토링실**: 학생 1명 + 멘토(Ver.2.9부터 화면 등장 없음, 서로 직접 연결, **녹화는 여기만**).
- **대기실**: 채팅 대신 **화상회의**. 기다리는 학생들과 운영진·연구원이 서로 얼굴을 보고 이야기합니다. 영상은 **Cloudflare Realtime SFU**가 중계(미술과 같은 방식 — 각자 영상 1개만 올리고, 여러 명이면 낮은 화질로 받음). **녹화하지 않습니다.**
- 학생 마이크는 **켠 채로** 들어갑니다(직접 끌 수 있음). 운영진은 학생 칸 위 「마이크 끄기」(두 번 누름)로 끌 수 있고, 학생이 다시 켤 수 있습니다.
- 학생끼리 서로 얼굴이 보입니다. 운영진·연구원은 **카메라를 켜거나 말했을 때만** 칸이 생깁니다(창만 열어 둔 사람은 보이지 않음).
- 차례가 되면 대기실 화상에서 빠져 멘토링실로 바로 이동(다음 학생 미리 연결은 그대로). **멘토링이 끝나면 「멘토링이 끝났습니다」 안내 후 바로 퇴장**(카메라·마이크 꺼짐, 대기실로 돌아오지 않음). 실수로 끝냈으면 [완료 취소] 후 학생이 다시 들어오면 됩니다.
- **대기실 채팅은 없앴습니다.** 「상단 고정 공지」는 그대로 — 학생 대기실 화상 위에 띠로 보입니다.
- 멘토 화면은 바뀌지 않습니다(대기실 보기 없음 — 부하를 늘리지 않음).

### Ver.2.7로 올릴 때 (한 번만)
1. 시트 「무용 온라인멘토링」 → 확장 프로그램 → Apps Script → `Code.gs`를 **Ver.2.3**(최신)으로 모두 바꿔 붙여넣기 → 💾 저장
2. ⚙ **프로젝트 설정 › 스크립트 속성**에 두 개 추가 — **미술 Apps Script에 넣은 값과 같은 값**:
   - `CF_SFU_APP_ID` · `CF_SFU_APP_TOKEN`
3. 함수 **`setup`** 실행 → 실행 로그에 `대기실 화상(SFU) 설정: 있음`, `SFU 연결 시험: 성공`이 나오면 됩니다.

## 4. 학생 화면 (기존 웹 대기실 기능 포함)
1. **본인 확인**: 이름 + 생년월일 + 녹화 동의
2. **카메라·마이크 확인**(Ver.2.6부터 유의사항 카드는 없음 — 안내는 사전 문자·메일로)
3. **대기실(한 화면)**: 상태(대기 중 · 내 앞 n명 · 현재 n번 진행 중 → 「다음 차례입니다」), 내 순서·대기실/멘토링 시각·날짜·멘토, 연결 점검·멘토 연결 준비 표시, **대기실 화상**(운영진 → 나 → 다른 학생 순, 말하는 사람 초록 후광, 마이크 꺼진 사람 빨간 표시), 아래 **마이크·카메라 켜고 끄기**, 화상 위 **상단 고정 공지**. PC는 왼쪽 화상 크게 · 오른쪽 상태, 휴대폰은 위 상태 · 아래 화상.
4. 차례가 되면 **알림음·진동·제목 깜빡임과 함께 자동으로 멘토링 화면**(카메라·마이크 자동 켜짐). 끝나면 **「멘토링이 끝났습니다」 안내 후 바로 퇴장**(카메라·마이크 꺼짐)
- 멘토링 화면: 아래 **마이크·카메라 켜고 끄기**, **오른쪽 위 「나가기」**(두 번 누름 — 「정말 나가기」).
- 새로고침해도 같은 탭이면 다시 입력하지 않고 카메라 확인부터. 「나가기」(두 번 누름)로 처음부터.
- 카카오톡에서 열면 기본 브라우저로 다시 엽니다. 확대·축소 막음(휴대폰).

## 5. 운영 화면 (기존 대기실 운영 기능 포함)

### 화면 구성
- **반반: 왼쪽 멘토링실·녹화 | 오른쪽 대기실(공지 + 대기실 칸)**. 좁은 화면(1000px 이하): [화면]/[대기실] 탭. 대기실 창: 대기실만 화면 가득.
- 위쪽: **회차 탭**(1회차·2회차·3회차·리허설), 화면 등장, 이 PC에서 녹화, 영상 소리, 알림음, 운영 순서, 알림 미리보기, **대기실 창 열기**, 나가기

### 녹화 — 멘토링은 항상 자동, 대기 시간은 「녹화 시작」부터 (Ver.2.10)
- **운영진으로 운영 화면(녹화 창)에 들어오면 누구나** 「녹화 준비」 창이 먼저 뜹니다(이름 제한 없음).
  1. **「저장 폴더 고르기」** → 녹화 폴더(바탕화면 등 **안의 새 폴더**) 고르기 → 크롬이 묻는 「파일 수정 허용」에 **허용**(「방문할 때마다 허용」이 보이면 그것).
  2. 같은 PC·크롬이면 폴더를 기억합니다. 권한이 남아 있으면 로그인 직후 바로 준비되고, 다시 물으면 「권한 허용하고 이 폴더에 저장」 한 번만 누르면 됩니다.
- 준비가 끝나면 **멘토링이 시작될 때마다 자동 녹화**합니다. 대기 시간은 「녹화 시작」을 누른 뒤부터 「녹화 중지·저장」까지 녹화합니다.
  - 멘토링 중: 학생별 파일 `261206_1650_3회차_02_이름.mp4`
  - 멘토링이 아닌 시간(「녹화 시작」을 눌렀을 때만): `261206_1630_3회차_대기.mp4` — 멘토 화면. 30분마다 나눔(`GAP_SPLIT_MIN`).
  - 대기 녹화 중이면 학생 영상이 들어오는 순간 학생 파일로 바꿔 빈틈이 없고, 대기 녹화가 꺼져 있으면 멘토링 시작 즉시 학생 파일을 시작합니다. 같은 이름 파일이 있으면 `-2`를 붙여 덮어쓰지 않습니다.
- 여러 운영진이 들어오면 **각자 PC에 따로 녹화**(서로 예비본). 학생 연결 점검은 먼저 들어온 한 사람이 맡습니다(「연결 점검 맡기」로 넘길 수 있음).
- **휴대폰·사파리 등 폴더 자동 저장이 안 되는 브라우저는 녹화하지 않습니다**(메모리 부족 방지). 녹화는 PC 크롬·엣지에서.
- 대기실 창(`?mode=room`)과 연구원은 녹화하지 않습니다.
- 나가기: 「나가기」 두 번 → 녹화 중인 파일을 저장한 뒤 나갑니다.
- 운영진 PC 녹화를 아예 끄려면 `config.js`의 `AUTO_RECORD_OPS: true`를 `false`로.

### 녹화가 반드시 남도록 (Ver.2.2)
- **예비 사본**: 녹화는 정한 폴더와 함께 크롬 안 저장 공간에도 동시에 저장됩니다. 창이 꺼지거나 PC가 멈춰도, 같은 PC·크롬으로 다시 들어와 녹화를 시작하면 끝나지 못한 파일이 **같은 이름으로 폴더에 복구**됩니다(이름 옆 크기가 0바이트였던 파일).
- **소리 막힘**: 크롬은 화면을 한 번도 누르지 않으면 소리를 막습니다. 이때는 영상만 녹화하고 녹화 칸에 「소리가 녹음되지 않고 있습니다」가 뜹니다 → 화면 아무 곳이나 한 번 클릭하면 소리 포함 새 파일로 이어집니다.
- **녹화 상태 줄**(녹화 칸 위): 「● 녹화 중 · 파일 이름 · 시간 · 크기 · 예비 사본 저장 중 · 폴더에 저장 중」. 문제가 있으면 노랑(주의)·빨강(녹화 안 됨, 깜빡임·알림음)으로 바뀝니다.
- 녹화가 8초 넘게 멈추면 그때까지를 저장하고 새 파일로 자동 재시작합니다.
- 녹화 창은 **최소화하지 말고** 띄워 두세요(다른 창 뒤에 있어도 됨).

### 대기실 창 (듀얼 모니터로 운영)
- 녹화 창의 **「대기실 창 열기」** → 대기실(학생 목록·알림·대기실 화상·공지)이 **새 창으로 옮겨 가고**, 녹화 창에서는 대기실이 사라져 **영상 화면이 창 전체**를 씁니다(로그인 이어받음). 새 창을 두 번째 모니터로 옮겨 쓰면 됩니다.
- 다시 한 화면으로: 녹화 창의 **「대기실 다시 합치기」**를 누르거나 대기실 창을 닫으면, 녹화 창에 대기실이 다시 나타납니다.
- 운영 Hub의 「대기실 운영 창」 주소로 다른 PC에서 대기실만 따로 열 수도 있습니다.
- 대기실 창에서 [시작]·[종료]를 눌러도 녹화 창이 자동으로 녹화·저장합니다.
- 팝업이 막히면 주소창 오른쪽 팝업 차단 아이콘에서 「허용」.

4. 시작 시각 → [시작](또는 「다음: ○○ 시작」). 다음 학생은 미리 연결돼 있어 **1초 안에** 바뀌고, 앞 학생 녹화는 자동 저장.
5. 빨간 테두리 칸(미접속) → 칸의 번호로 **전화**. 지연되면 상단 고정 공지.
6. 마지막 학생 [이 학생 종료] 두 번 → 녹화 저장 확인.

## 7. 그 밖의 기능 (Ver.1.x에서 이어짐)
- **발언자 표시**: 말하는 사람 영상에 초록 후광 + 왼쪽 아래 소리 아이콘(학생·멘토·운영 화면 모두).
- **멘토 화면**: 오른쪽 위 큰 카운트다운, 8분 뒤 질의응답, 1분 전 테두리 깜빡임·가운데 알림·알림음, 시간 초과 표시
- (Ver.2.9에서 버튼 숨김) **화면 등장**(연구원·운영진, 멘토링 전·최대 3명): 기본 마이크 꺼짐, **스페이스 누르는 동안만 말하기**(휴대폰은 「누르고 말하기」), 「마이크 항상 켜짐」 전환. 멘토링 시작 시 자동으로 내려감. 이어폰 권장.
- **녹화**: **FHD 1920×1080**(창 크기와 상관없이 이 크기로 저장, 영상 6Mbps — 10분에 약 450MB), 두 사람 화면 좌우 합성 + 두 음성, 학생별 파일 `261206_1732_3회차_01_이름.mp4`(맨 앞이 녹화 시작 날짜_시각), 정한 폴더에 **창 없이 자동 저장**(쓰는 중 `…crswap`). 바탕화면·다운로드 폴더 자체가 아닌 그 **안의 새 폴더**를 고르세요.
- **빠른 전환**: 연결된 사람끼리는 데이터 통로로 시작·종료를 바로 전달(서버에도 기록). 대기실 창(영상 없음)에서 누르면 서버를 거쳐 1~2초.
- **중계 서버**: Cloudflare TURN(월 1,000GB 무료). 키가 없으면 구글 STUN만.
